# ⚡ Физика 9 класс — тренажёр для закрытия долгов

Интерактивный учебный сайт для подготовки ученика 9 класса к сдаче долгов по физике.

Сайт рассчитан прежде всего на **практику**: теории немного, а основной акцент сделан на решении задач, выборе правильной формулы и проверке результата.

## 📚 Темы

### 🚗 Равномерное прямолинейное движение

Тренировка по основным типам задач:

- скорость;
- путь;
- время;
- связь между величинами `v`, `s` и `t`;
- перевод единиц скорости;
- работа с графиками движения;
- задачи, где нужно самостоятельно определить подходящую формулу.

Основные формулы:

```text
v = s / t
s = v · t
t = s / v
```

### 🪂 Ускорение свободного падения

Практика по задачам на:

- ускорение свободного падения `g`;
- скорость падающего тела;
- путь при свободном падении;
- время падения;
- изменение скорости тела при падении;
- выбор нужной формулы в зависимости от условия задачи.

В расчётах используется школьное приближение ускорения свободного падения:

```text
g ≈ 10 м/с²
```

## 🔥 Финальная «Битва»

В финальном режиме задачи двух тем перемешиваются.

Здесь уже нельзя просто выбрать раздел и использовать одну знакомую формулу — нужно сначала понять, **какое физическое явление описано в задаче и что именно требуется найти**.

## 🚀 Как открыть сайт на компьютере

1. Скачайте `index.html`.
2. Откройте файл двойным нажатием.
3. Сайт откроется в браузере.

Дополнительные программы устанавливать не нужно.

## 🌐 Как разместить сайт на GitHub Pages

### 1. Создайте репозиторий

На GitHub создайте новый репозиторий, например:

```text
semen-physics-debts
```

### 2. Загрузите файлы

В корень репозитория загрузите:

```text
index.html
README.md
```

**Важно:** `index.html` должен находиться непосредственно в корне репозитория, а не внутри дополнительной папки.

### 3. Включите GitHub Pages

Откройте:

**Settings → Pages**

В разделе **Build and deployment** выберите:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

Нажмите **Save**.

Через некоторое время GitHub Pages создаст ссылку на сайт.

## 👨‍🏫 Как использовать на занятии

Оптимальный сценарий занятия:

1. **5 задач — равномерное прямолинейное движение.**
2. Проверить ошибки и разобрать, почему выбранная формула подходит или не подходит.
3. **5 задач — свободное падение.**
4. Отдельно разобрать ошибки в единицах измерения и формулах.
5. В конце пройти **«Битву»**, где темы смешаны.

Такой формат позволяет не просто проверить память формул, а понять, умеет ли ученик самостоятельно распознавать тип задачи.

## 🎯 Цель проекта

Главная задача тренажёра — помочь ученику **закрыть пробелы в двух темах через практику**, постепенно перейти от задач с понятным алгоритмом к задачам, где формулу и способ решения нужно определить самостоятельно.
